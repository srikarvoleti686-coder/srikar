## 📖 Description

A curated collection of core **C and C++** implementations focusing on foundational computer science principles, memory layout, array algorithms, sorting routines, and hardware monitoring simulations.

---

## 📂 Repository Contents & Catalog

### 1. 🔍 Sorting & Searching Algorithms
- `LINEAR.c` — Linear search algorithm on unsorted datasets.
- `bineary search.c` — Binary search implementation with $O(\log N)$ time complexity.
- `merge sort.c` — Divide-and-conquer recursive merge sort algorithm.
- `SORTING AN ARRAY.C` — Comparative array sorting routines.

### 2. 📊 Array Manipulation & Matrix Operations
- `2d array.c` — Multi-dimensional memory indexing and pointer arithmetic.
- `5x5.cpp` — 5x5 matrix transformations and coordinate manipulation.
- `dynamic array.c` — Heap memory allocation with dynamic resizing (`malloc`, `realloc`, `free`).
- `duplicate elements.c` — Frequency mapping and duplicate detection in linear memory.
- `multi-dimensional array from user for 5 students with 3 .c` — Multi-record array structuring.
- `second array.c`, `smallest.c`, `avg.c`, `frequency.c` — Statistical and extreme-value extractions.

### 3. ⏱️ Systems & Hardware Monitoring Concepts
- `WATCH DOG.c` — Watchdog timer / heartbeat routine simulator for crash recovery and process liveness monitoring.
- `crash.c`, `hack.c`, `correct.c` — Edge-case testing, memory faults, and defensive programming patterns.
- `engine.c`, `log.c` — Basic state machines and modular logging routines.
- `voter system.cpp` — Object-oriented stateful voting logic in C++.

## 🛠️ Compilation & Execution

To compile any source file using GCC or Clang:

```bash
# Compile a C file
gcc -O2 -Wall -Wextra "merge sort.c" -o merge_sort
./merge_sort

# Compile a C++ file
g++ -O2 -std=c++17 -Wall "5x5.cpp" -o matrix_5x5
./matrix_5x5
```
